# Этап 2. Локальная модель текстового риска

Модель — обученный классификатор scikit-learn, а не набор правил и не внешний API. Исходные сообщения пользователей не пишутся в MySQL и не попадают в журнал. Процент риска в интерфейсе не показывается: калибровка вероятностей не подтверждена.

## Что проверено на машине

- Память: 16 ГБ.
- Свободно на диске данных: около 15 ГБ, занято примерно 93%.
- MySQL Community Server 9.4.0, база `senimradar_ai`. Схема этапа 1 не менялась.
- XLM-RoBERTa и другое дообучение нейросети не запускались: для этого не хватает свободного места и запаса памяти.

## Датасеты

### Не использован: FraudLens

`Abdurohman/fraudlens-ru-v1`, лицензия CC BY 4.0, около 15 МБ, 6327 русских записей из публичных антифрод-каналов Telegram. Это описания схем и новости о мошенничестве, а не сами мошеннические сообщения. Безопасного класса нет. Казахский заявлен только в планах. Такие тексты не размечались как мошеннические примеры.

### Использован: Adaption scam dataset

`dokster/adaption-scam-dataset-ru-en-v1`

- Лицензия: Apache-2.0. Коммерческое использование разрешено с сохранением лицензии и указания источника.
- Происхождение: синтетические шаблоны. Русские строки — перевод английских шаблонов, а не отдельная живая выборка и не казахские данные.
- Файл обучения: 2324 строки. Опасные `dangerous` — 1391, безопасные `safe` — 409, `needs_check` — 358, `suspicious` — 166.
- Языки файла обучения: английский 1200, русский 1124, казахский 0.
- Официальная проверочная выборка не пересекается с обучением по идентификаторам: 632 английских и 316 русских сообщений.
- Смещение: сценарии в основном англо-американские. Российские и казахстанские схемы вроде «Госуслуг» представлены слабо. Качество на живых сообщениях по этим цифрам не доказывается.

Сообщения с одним шаблоном, переводом и тем же текстом после удаления номеров не попадали и в обучение, и в тест. Из-за этого из файла обучения исключено 1997 строк, связанных с официальным тестом.

После разделения, seed 42:

| Обучение | 259 | 257 | 2 |

Классы обучения: `dangerous` 100, `safe` 61, `needs_check` 55, `suspicious` 43.

## Модель

`tfidf-logreg-0001`

- Слова: TF-IDF, n-граммы 1–2.
- Символы: TF-IDF `char_wb`, n-граммы 3–5.
- Классификатор: логистическая регрессия, `class_weight="balanced"`, solver `lbfgs`.
- Константа `C` выбрана по macro-F1 на валидации из 0.25, 1 и 4. Выбрано 0.25.
- Случайное зерно: 42.
- scikit-learn 1.9.1, numpy 2.5.5.
- Размер артефакта: 554952 байта.
- Среднее время одного предсказания на проверочной выборке: 0.051 мс.
- Порог неуверенности взят как 75-й перцентиль отрыва вероятностей на ошибочных ответах валидации: 0.089624.

Категории интерфейса соответствуют классам датасета: `safe` → низкий, `suspicious` → средний, `dangerous` → высокий, `needs_check` → не определён. Это не подобранный процентный порог.

Ожидаемая ошибка калибровки на валидации: 0.517518. Порог для показа процента был заранее задан как 0.05. Процент скрыт.

Macro-F1 модели: **0.452784**. Macro-F1 простого словарного baseline: **0.20626**. Baseline не используется в API.

Общая матрица ошибок, порядок классов `safe`, `needs_check`, `suspicious`, `dangerous`:

Для класса `dangerous` против остальных: доля ложных срабатываний 0.056604, доля пропусков 0.66879.

| ru | evaluated | 316 | 0.817608 | 0.216561 |
| en | evaluated | 632 | 0.242976 | 0.894904 |

Русский результат считается на синтетическом переводе шаблонов, которые не входили в обучение. Английский тест слабый, потому что после удаления связанных шаблонов в обучении осталось 2 английских строки. Поэтому интерфейс не показывает английский вердикт. Казахский вердикт тоже не показывается.

Валидационный macro-F1 0.911371 измерен на остатке тех же шаблонов и не заменяет независимый тест.

## Повторное обучение

Из каталога `senimradar-ai/backend`, когда файлы уже лежат в `data/raw`:

```bash
source .venv/bin/activate
python -m training.train
```

Файлы, если их нужно скачать заново:

```bash
mkdir -p data/raw
curl -fsSL -o data/raw/train_0.jsonl https://huggingface.co/datasets/dokster/adaption-scam-dataset-ru-en-v1/resolve/main/data/train_0.jsonl
curl -fsSL -o data/raw/eval_en.jsonl https://huggingface.co/datasets/dokster/adaption-scam-dataset-ru-en-v1/resolve/main/data/eval_en.jsonl
curl -fsSL -o data/raw/eval_ru_en.jsonl https://huggingface.co/datasets/dokster/adaption-scam-dataset-ru-en-v1/resolve/main/data/eval_ru_en.jsonl
```

Сырые файлы в Git не входят. В репозитории остаются `backend/app/ml/artifacts/model.joblib` и `model_card.json`. Карточка хранит SHA-256 исходных файлов.

Запуск API и интерфейса описан в [setup-macos.md](setup-macos.md).
