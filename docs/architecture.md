# Архитектура этапа 1

SenimRadar AI — один репозиторий с интерфейсом и API. Отдельных сервисов модели пока нет.

## Поток запроса

1. Человек вставляет текст в интерфейс.
2. `POST /api/v1/analysis/text` проверяет JSON: длина до 8000 символов, язык `ru`, `kk`, `en` или `unknown`.
3. Ошибки проверки возвращают код поля и не возвращают сам текст.
4. Тело больше 48 КБ отклоняется до разбора.
5. `assess_text()` не получает текст. Оно сообщает, что модель не настроена.
6. Ответ `503` содержит пустые `risk_level`, `risk_score` и `model_version`.

Флаг `text_model_configured()` сейчас всегда `False`. Пока вместо него не появится настоящий вызов модели, включать его нельзя: API останется недоступным и не начнёт выдумывать риск.

## Интерфейс

React, TypeScript, Vite, Tailwind CSS, React Router и TanStack Query.

Язык по умолчанию — русский. Переключатель сохраняет `ru` или `kk` в `localStorage`. Казахский интерфейс — перевод оболочки, а не доказательство, что будущая модель понимает казахский.

Разделы скриншота, ссылки и голоса показывают будущую форму, но элементы ввода отключены.

## Данные

База — MySQL `senimradar_ai`, InnoDB, кодировка `utf8mb4` для русского, казахского и английского. Идентификаторы хранятся как `CHAR(36)`.

Таблицы: `users`, `user_settings`, `model_versions`, `analysis_records`, `detected_threats`, `analysis_indicators`, `analysis_recommendations`, `audit_events`.

В `analysis_records` нет колонки исходного сообщения. Пароли не хранятся. История по умолчанию выключена полем `history_consent`. На этапе 1 API эти таблицы не заполняет.

Миграция: `backend/alembic/versions/20261122_0001_initial_schema.py`.

## Защита этапа 1

- CORS разрешает локальный Vite на портах 5173 и 5174, для `localhost` и `127.0.0.1`.
- POST ограничен 120 запросами в минуту на один адрес клиента внутри одного процесса. Это не кластерный лимитер.
- Ответы API не кэшируются и закрыты от встраивания во фрейм.
- Журнал не получает тело запроса. Ошибка базы записывается типом исключения, без строки подключения.

## Этап 2

Локальная модель — TF-IDF и логистическая регрессия. Метрики, лицензия датасета и команды повторного обучения записаны в [stage-2.md](stage-2.md). Казахский язык не оценивался. Английский независимый тест слабый, поэтому вердикт на английском не показывается. Процент риска скрыт.
