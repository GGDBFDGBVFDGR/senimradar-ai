# SenimRadar AI

Платформа цифрового доверия: «Проверь, прежде чем доверять».

Сейчас готов **этап 1** — рабочий каркас продукта. Модель обнаружения мошенничества ещё не подключена. Если отправить текст на анализ, API честно отвечает `503` и не выдаёт уровень риска.

## Что уже работает

- Backend на FastAPI: проверка живости, готовность базы, список возможностей и проверка текста.
- Запрос текста проверяется по длине и языку. Содержимое не сохраняется и не пишется в журнал.
- Если модель не настроена, ответ содержит `status: unavailable`, а `risk_level` и `risk_score` остаются пустыми.
- Интерфейс на React: обзор, сканер, заготовки следующих разделов, русский и казахский языки.
- Схема PostgreSQL и миграция Alembic. Исходный текст, скриншот и запись в таблицах не предусмотрены.
- История проверок выключена.

## Что ещё не работает

- Классификация мошенничества в тексте — этап 2.
- Скриншоты — этап 3.
- Разбор ссылок без их открытия — этап 4.
- Объяснения на данных реальной модели — этап 5.
- Голос — этап 6.
- Учётные записи и история с согласием — этап 7.

## Окружение

Проверено на этом Mac:

- macOS 15.5, Apple Silicon
- Python 3.13.0
- Node.js 25.2.1 и npm 11.6.2
- PostgreSQL 14.17 установлен через Homebrew и принимает подключения на порту 5432
- Роль `senimradar` в этой базе ещё не создана, поэтому миграция не применена
- Docker не установлен
- Порт 5173 уже занят другим локальным Vite. Если порт занят, Vite откроет 5174. Оба адреса разрешены в CORS.

Системные пакеты и служба PostgreSQL из этого этапа не устанавливались и не запускались.

## Первый запуск

Из каталога `senimradar-ai`:

```bash
python3 -m venv backend/.venv
source backend/.venv/bin/activate
pip install -r backend/requirements.txt
```

```bash
cd frontend
npm install
```

Два терминала:

```bash
source backend/.venv/bin/activate
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

```bash
cd frontend
npm run dev
```

Интерфейс по умолчанию: <http://127.0.0.1:5173>. На этой машине порт 5173 занят, поэтому сейчас Vite открыт на <http://127.0.0.1:5174>.

Проверка API: <http://127.0.0.1:8000/api/v1/health>

Описание API: <http://127.0.0.1:8000/docs>

Те же команды запуска лежат в `scripts/dev-backend.sh` и `scripts/dev-frontend.sh`.

## База данных

API поднимается и без PostgreSQL. В этом случае `/api/v1/health` отвечает `200`, а `/api/v1/health/ready` — `503` с `database: unavailable`.

Когда появится Docker:

```bash
docker compose up -d
cd backend
source .venv/bin/activate
alembic upgrade head
```

Без Docker можно поднять уже установленный PostgreSQL 14. Команды и ограничения порта описаны в [docs/setup-macos.md](docs/setup-macos.md). Пароль из `.env.example` подходит только для локальной машины.

## Конфиденциальность на этом этапе

- Текст уходит на локальный API, проверяется и отбрасывается.
- Внешний AI-провайдер не подключён. Ключей в репозитории нет.
- Подозрительные ссылки не открываются: поля загрузки и адреса выключены.
- Журнал пишет тип ошибки и путь, но не тело запроса.
